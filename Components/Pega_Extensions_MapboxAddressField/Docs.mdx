# Mapbox Address Field

The Mapbox Address Field is the field-type counterpart to the Mapbox Address Picker widget. It binds to one Pega text property and supports address search plus browser current-location lookup. Use the widget when you need to populate multiple address fields; use this field when you need one address value in a normal form field slot.

Configure a restricted public `pk...` Mapbox token. Never use an `sk...` secret token in browser code.

# Split Flap Text Field

The Split Flap Text Field is the field-type counterpart to the Split Flap Text widget. It binds to one Pega text property through the normal field API and displays an animated preview beneath the editable input. Use the widget for display-only status text; use this field when a case worker must enter or update the text.

The tile width automatically follows the current text length.

# Split Flap Text

Split Flap Text displays short messages as animated split-flap character tiles. It is designed for prominent status, readiness, or announcement text in a page or case view.

<Controls />

## Configuration

Add the **Split Flap Text** widget to a page or case view and set only the `text` property, for example:

```text
LAUNCH READY
```

The widget performs one split-flap animation when the text is rendered. Keep the text short enough to fit the available layout width.

The tile count automatically matches the text. For example, `HELLO` renders five tiles and `WELCOME` renders seven.
